# LuciOS documentation — v1.1 change log

**October 22, 2026 · Design decision update**

## Reason

The portfolio's app selection/display concept was redesigned, and interactive project replicas were removed to meet the short academic deadline. All implementation-bearing documents have been revised together so Codex receives consistent instructions.

| Previous draft | Current v1.1 instruction |
| --- | --- |
| Radial, steampunk launcher | **Overhead rotating dry-cleaner-style app rail**, hanging pixel icon tags, edge hover/focus scrolling |
| Floating, draggable, stacked windows | **Single black display frame** lowered mechanically over the desktop with bronze pipes and holographic content |
| Dummy sample preview apps for three projects | **Three genuine screenshots per project, selected code highlights, direct per-project GitHub link at bottom** |
| Mechanical details concentrated on dial/window border | **Steampunk + cyberpunk throughout**: rail, hand, pipe border, gears, pressure valve, hologram |
| Terminal steam while processing | **Unchanged and clarified**: no steam while typing; valve vents only during valid processing, never on invalid commands |
| Complex visual features required immediately | **Phase** into basic functionality first; hand/physics remain progressive enhancements |
| Mobile-themed fake OS | **Deferred**; narrow viewport has a basic, readable Portfolio View to satisfy accessibility expectations |
