# LuciOS

LuciOS is Luci Crow's professional technology portfolio, built as an original mechanical-futurist interface. The submission edition prioritizes complete, accessible professional content while establishing the visual foundation for the larger overhead app rail, pixel-shadow hand, and holographic display concept.

## Stack

- React
- TypeScript
- Vite
- CSS

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

The site is static and requires no backend, secrets, or database.
